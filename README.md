============================================================
              LAPTOP BATTERY HEALTH CHECKER
                  Battery Diagnostic Tool
============================================================

A simple Windows diagnostic utility for checking the
condition and capacity health of a laptop battery.

Designed for laptop buyers, sellers, technicians, and
resellers who need a quick way to verify battery condition
before purchasing, selling, or servicing a laptop.


WHAT IT CHECKS
------------------------------------------------------------

• Battery Health / Capacity Retention
• Design Capacity
• Full Charge Capacity
• Capacity Loss / Battery Wear
• Battery Cycle Count
• Battery Manufacturer
• Battery Model
• Battery Serial Number
• Battery Chemistry
• Current Battery Status
• Laptop Model
• Windows Information


HOW BATTERY HEALTH IS CALCULATED
------------------------------------------------------------

Battery Health is calculated using:

Full Charge Capacity ÷ Design Capacity × 100

Example:

Design Capacity:       47,000 mWh
Full Charge Capacity:  46,880 mWh

Battery Health:        99.7%
Capacity Loss:          0.3%


BATTERY CONDITION
------------------------------------------------------------

95% – 100%     EXCELLENT
90% – 94%      VERY GOOD
80% – 89%      GOOD
70% – 79%      FAIR
60% – 69%      WORN
Below 60%      POOR


HOW TO USE
------------------------------------------------------------

1. Extract all files into the same folder.

2. Right-click "Check_Battery.bat" and select
   "Run as administrator" if required.

3. The tool will automatically collect the available
   battery information from Windows.

4. A battery diagnostic report will be generated
   automatically.

5. The report will open in your default web browser.


IMPORTANT
------------------------------------------------------------

Battery Health represents the battery's remaining
capacity compared with its original designed capacity.

It does NOT represent the exact amount of runtime
remaining.

Actual battery runtime depends on:

• CPU/GPU usage
• Screen brightness
• Wi-Fi/Bluetooth usage
• Background applications
• Power settings
• Battery temperature
• Laptop hardware
• Windows power management


DATA AVAILABILITY
------------------------------------------------------------

Some laptop manufacturers or battery controllers may not
provide certain information such as Cycle Count or Design
Capacity.

When information is unavailable, the tool may display
"N/A" instead of estimating or inventing a value.

If Design Capacity is not directly available through
Windows system information, the tool attempts to retrieve
the information through Windows' battery report.


BEST USE
------------------------------------------------------------

Recommended for:

• Used laptop inspection
• Laptop buying
• Laptop reselling
• Battery condition verification
• Pre-sale diagnostics
• Laptop maintenance
• Technician testing
• Inventory documentation


DISCLAIMER
------------------------------------------------------------

This tool provides a software-based battery capacity
diagnostic using information reported by Windows and the
laptop's battery controller.

It is intended as a diagnostic aid and should not be
considered a substitute for professional battery testing.

Battery health results may vary depending on the accuracy
and availability of information provided by the laptop's
hardware and firmware.
